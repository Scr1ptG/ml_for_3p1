# Тема 3. Находим лица на видео

LXP: «Нахождение лиц в видеопотоке с помощью OpenCV» · 2 балла.

| Файл | Что это |
|---|---|
| `slides.html` | Презентация (12 слайдов). Стрелки или пробел — листать, **F** — полный экран, **N** — заметки преподавателя |
| `lesson.ipynb` | Практика в Colab: 13 заданий с автопроверкой (рамка, вырезать, детектор, несколько лиц, лица на видео) и шаблоны КТ |
| `faces_local.py` | То же вживую с веб-камерой на компьютере: `r` — запись лиц в `video/`, `m` — все лица / одно, `q` — выход |
| `quiz.json` | 12 вопросов квиза (в списке на экране преподавателя — «Тема 3») |

**Открыть практику:** [в Colab](https://colab.research.google.com/github/Scr1ptG/ml_for_3p1/blob/main/03-faces/lesson.ipynb) → **Файл → Сохранить копию на Диске**.
