# Контрольная работа по работе с видео

LXP: «Контрольная работа по работе с видео». Работаем **локально** на компьютере с веб-камерой.

## Подготовка (5 минут)
```bash
pip install opencv-python numpy
python check_camera.py
```
`check_camera.py` проверяет камеру и печатает **код каждой нажатой клавиши** — так можно узнать коды `s` и `t`.

Если камера не открылась: закройте браузер/Zoom, где включена камера, или попробуйте `cv2.VideoCapture(1)`.

## Задание
Откройте `control_template.py`, впишите фамилию и вариант и допишите места `TODO`.

| | Что сделать | Балл |
|---|---|---|
| 1 | Клавиша **s** включает и выключает усиление канала **на 10%**: вариант 1 — красный, 2 — синий, 3 — зелёный | 5 |
| 2 | Клавиша **t** включает и выключает **поворот на 180°** | 5 |

Повторное нажатие клавиши возвращает как было. Оба эффекта могут работать одновременно.

**Сдать:** файл `.py` в LXP и показать работу преподавателю вживую.

## Что можно
Свои ноутбуки тем 1–4, документацию OpenCV, шпаргалку ниже. Нельзя — помогать соседу и нейросети.

## Шпаргалка
| Что | Код |
|---|---|
| порядок каналов в OpenCV | **B, G, R** → синий `[:, :, 0]`, зелёный `[:, :, 1]`, красный `[:, :, 2]` |
| +10% без переполнения | `np.clip(канал.astype(np.float32) * 1.1, 0, 255).astype(np.uint8)` |
| поворот на 180° | `cv2.rotate(frame, cv2.ROTATE_180)` или `cv2.flip(frame, -1)` |
| код клавиши | `key = cv2.waitKey(1) & 0xFF` |
| сравнить с буквой | `key == ord("s")` |
| переключатель | `flag = not flag` |

> ⚠️ Почему не просто `frame * 1.1`: в `uint8` после 255 идёт 0, и яркие места станут тёмными. Поэтому сначала float, потом `clip`.
