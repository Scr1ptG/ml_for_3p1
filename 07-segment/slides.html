Разметка

Схема BIO: где сущность начинается

ДмитрийB-PER МедведевI-PER иO ВладимирB-PER ПутинI-PER

B начало, I продолжение, O вне сущности.

Без B два человека подряд слились бы в одного.

Нарушение: I-ORG после O. Простая сеть такое допускает, CRF-слой запрещает.

Метрики

Почему accuracy врёт

Ленивая модель

всё помечает O: accuracy около 85%, найдено 0 сущностей

F1

P = верные / найденные
R = верные / существующие
F1 = 2PR / (P + R)

В ноутбуке F1 считается по словам, макро-среднее без O.

Строже считает seqeval: сущность верна, только если совпали все её слова.
