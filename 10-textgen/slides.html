Читать текст с памятью умеет LSTM (прошлая тема). Значит, нужно две LSTM: одна слушает, другая говорит.

Seq2Seq

Как работает переводчик-синхронист

👂 Кодировщик

дослушивает фразу до конца и держит смысл в голове

LSTM читает вопрос → память (h, c)

🗣 Декодировщик

по смыслу произносит ответ слово за словом

LSTM стартует с (h, c) и пишет ответ

Seq2Seq = Sequence to Sequence, «последовательность в последовательность». Длины вопроса и ответа могут быть разными.

Обучение

Учим со «шпаргалкой» (teacher forcing)

Декодировщику на каждом шаге даём правильное прошлое слово, а он угадывает следующее:

Шаг123
Вход декодировщика<BOS>ждётвас
Должен угадатьждётвас<EOS>

Выход — это вход, сдвинутый на одно слово. В ноутбуке это одна функция в две строки.

Так сеть учится быстро: одна ошибка не ломает весь ответ.

Ответ

Как бот пишет ответ

  1. Кодировщик читает вопрос → память
  2. Даём декодировщику <BOS> → оценки всех слов
  3. Выбираем слово: самое вероятное или случайно с температурой
  4. Подаём выбранное слово обратно → следующее слово
  5. Пока не выпадет <EOS> или не кончится лимит

Шпаргалки больше нет: бот опирается на свои же слова.

Код

Seq2Seq в PyTorch: главное — передать память

class Seq2Seq(nn.Module):
    def __init__(self, vocab):
        super().__init__()
        self.emb = nn.Embedding(vocab, 128)
        self.encoder = nn.LSTM(128, 256, batch_first=True)
        self.decoder = nn.LSTM(128, 256, batch_first=True)
        self.head = nn.Linear(256, vocab)

    def forward(self, q, dec_in):
        _, (h, c) = self.encoder(self.emb(q))               # смысл вопроса
        out, _ = self.decoder(self.emb(dec_in), (h, c))     # старт со смысла
        return self.head(out)
