# Квиз

Студенты: `https://scr1ptg.github.io/ml_for_3p1/` · преподаватель: `…/quiz/host.html`

## Как устроен квиз
* Связь идёт через бесплатный публичный MQTT-брокер (EMQX, запасной — HiveMQ), сервер не нужен. Трафик — сотни байт на вопрос, страница весит около 60 КБ.
* Код комнаты из 6 цифр. По первой цифре определяется брокер.
* Верные ответы уходят студентам только после последнего вопроса. Во время игры их знает только экран преподавателя.
* Очки: `база × (1 − 0,5 × время_ответа / лимит)`. База: ★ 500, ★★ 1000, ★★★ 1500. Неверно — 0. На вопрос с несколькими ответами засчитывается только полностью верный набор.
* Экран преподавателя переживает перезагрузку: на стартовой странице будет кнопка «Продолжить».
* Итоги выгружаются в CSV для Excel (с правильными ответами во второй строке) и в JSON.
* Пробел или Enter — следующий шаг, стрелки — листать разбор.

## Формат файла вопросов
```json
{
  "title": "Пара 3. Название",
  "defaults": { "time": 25, "difficulty": 1 },
  "questions": [
    {
      "text": "Текст вопроса. `код` в обратных кавычках выделяется",
      "code": "необязательный блок кода\nв несколько строк",
      "image": "необязательная картинка: путь от файла квиза или URL",
      "options": ["A", "B", "C", "D"],
      "correct": 1,
      "difficulty": 2,
      "time": 30,
      "explain": "Пояснение — показывается в разборе после игры"
    }
  ]
}
```
* `correct` — номер верного варианта **с нуля**. Если верных несколько — массив: `[0, 2]`.
* `options` — от 2 до 6 вариантов. Варианты перемешиваются, если это включено в настройках.
* `time` — от 5 до 120 секунд, `difficulty` — 1, 2 или 3 (или своё число очков в `points`).
* Файл можно не загружать на сайт: на экране преподавателя его просто перетаскивают в окно.
* Чтобы квиз появился в списке, добавьте строку в `quiz/quizzes/index.json`. Путь к файлу урока пишется от папки `quizzes`: `"../../01-video/quiz.json"`.
